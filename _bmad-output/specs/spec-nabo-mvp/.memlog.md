- (decision) Build a fully functional, stateful client-side MVP persisted via localStorage with live intent intake, real matching engine, calendar export, and recurrence feedback.
- (capability) CAP-1: User can configure their profile (name, neighborhood, interests, free time slots) to drive matching.
- (capability) CAP-2: User can input new contacts into their Sometime List with informal context (where met, shared interests).
- (capability) CAP-3: User can create a new hangout intent or community volunteer request with target activity and timing.
- (capability) CAP-4: Autonomous matching engine dynamically pairs intents with matching contacts and generates proposal cards with Why You context.
- (capability) CAP-5: Social Shield guarantees private decline with zero disclosure to the other person.
- (capability) CAP-6: Go as Two pairing lets users attend community or group events with an arrival buddy to reduce newcomer anxiety.
- (capability) CAP-7: Real calendar export generates valid downloadable .ics iCal files and Google Calendar links for confirmed events.
- (capability) CAP-8: Anonymous post-event recurrence loop captures mutual thumbs-up to feed repeat low-pressure meetup recommendations.
- (capability) CAP-9: LocalStorage persistence retains all customized profiles, contacts, and confirmed events with a 1-click Reset Demo button.
- (constraint) Runs standalone in browser without external backend server dependencies, making it 100% resilient for hackathon judging.
- (nongoal) No multi-device sync or cloud user accounts in MVP scope.
